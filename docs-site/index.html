Jekyll in the browser

A faithful JavaScript port of Jekyll's static site engine. Hand it files, get back rendered HTML. No Ruby, no filesystem — it runs on a plain JS object, so your agent, app, or IDE can build Jekyll sites anywhere.

Try the playground View on GitHub

$ npm install jekyll-js

Why jekyll-js

Everything an AI agent, browser tool, or editor needs to build and preview Jekyll sites client-side.

🚫

No Ruby required

The entire engine is pure JavaScript. Drop it into any page, worker, or Node process — no toolchain, no WASM blob, no server round-trip.

💾

VFS-based

Sites live in a plain { path: content } object. Perfect for sandboxes, in-memory editors, and agents that generate files on the fly.

🔌

JS Plugin API

Generators, tags, filters, and hooks — as expressive as Jekyll's Ruby plugin API, written in JavaScript. Port real plugins, including jekyll-redirect-from and jekyll-feed.

🎯

True parity

Verified against real Jekyll with a native Ruby oracle: byte-identical feed, sitemap, SEO tags, redirects, and Minima theme output. Honest scoreboard, no fake green.

🌐

Browser & Node

A 244KB core bundle works from file://. Heavy features (Sass, syntax highlighting) lazy-load as plugins. Plus a CLI with build and serve.

🤖

AI-ready

Built so agents can preview what they build. Fluent builder API, lifecycle events, and TypeScript types make programmatic site generation feel native.

Quick start

Terminal
$ npm install jekyll-js
build.js
import { JekyllEngine } from 'jekyll-js';

const pages = await JekyllEngine.render({
  '_config.yml': 'title: My Site\n',
  'index.md': '---\nlayout: default\n---\n# Hello world',
});

console.log(pages[0].content);
